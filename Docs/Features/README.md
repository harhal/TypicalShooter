# Фичи TypicalShooter

Живая документация игровых фич: что уже работает, как устроено, как проверяется и что осталось.
Обновляется вместе с кодом — изменение поведения фичи и правка её документа идут в одном коммите.

| Фича | Статус | Документ |
|------|--------|----------|
| Предметы и фрагменты | ✅ работает | [Items.md](Items.md) |
| Инвентарь на гекс-сетке | 🟡 работает на сервере (мультиплеер не проверен) | [Inventory.md](Inventory.md) |
| Контейнеры предметов в мире | ✅ работает | [ItemsContainer.md](ItemsContainer.md) |
| Взаимодействие (E / X) | ✅ работает | [Interaction.md](Interaction.md) |
| Экран инвентаря и UI сетки (мышь + геймпад) | ✅ работает | [InventoryUI.md](InventoryUI.md) |
| Гекс-сетка (плагин) | ✅ работает | [HexGrid.md](HexGrid.md) |
| Стрельба: абилки основной / альтернативной атаки | ✅ работает (снаряды; хитскан / коллайдер — позже, мультиплеер не проверен) | [Shooting.md](Shooting.md) |
| Энергосеть предметов: источники, приёмники, коннекторы | ✅ готово (влито в `main`) | [ItemPowerGrid.md](ItemPowerGrid.md) |
| Враги: стрелки, волны, ИИ на StateTree | ⚪ в разработке (`feature/enemies`) | [Enemies.md](Enemies.md) |
| Мультиплеер | ⚪ репликация написана, не проверялась | см. [Inventory.md](Inventory.md#репликация) |

Статусы: ✅ работает и покрыто тестами · 🟡 частично · 🔴 сломано · ⚪ не начато / не проверено.

## Как обновлять

- Новая фича → новый файл по [шаблону](_Template.md) + строка в таблице выше.
- Поменялось поведение, управление, контент или тесты → правим разделы фичи и её статус.
- Пункты из «Открытых задач» после реализации переносим в описание (а не просто удаляем).
- Пишем то, что не видно из кода с первого взгляда: зачем, как связано, где грабли.
  Сигнатуры функций не копируем — даём имена классов/файлов.
- В каждом документе внизу — дата последней сверки с кодом.
